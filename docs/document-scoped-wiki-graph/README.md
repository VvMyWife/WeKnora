## 范围与含义

按档案图谱仅使用已有 Wiki 页面及链接。共享节点表示其来源包含至少两份所选档案；跨来源链接表示端点可追溯到不同的所选档案，不代表模型证明了档案之间的业务关系。无关联时显示空结果，不回退为全库图谱。

选择档案使用 knowledge ID；重复名称不视为同一档案。页数与 PDF 版本定位沿用既有溯源功能，不推算历史页码。
